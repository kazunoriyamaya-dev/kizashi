## 2. 実装への落とし込み（差分3項目）

### 2.1 ペアレッスン（Q001）

- `tickets.lesson_format` カラムを追加：`solo` / `pair`
- `pair` チケットは1回の消化で2名が同時受講
- 予約時に「ペアの相手」を選択：
  - 自分の `children` から複数選択（最大2名）
  - フリーテキスト入力（外部参加者のフルネーム/年齢など）
- `reservations.pair_participants` (jsonb) に `[{type: 'child', child_id: '...'}, {type: 'free_text', name: '...', note: '...'}]` 形式で保存
- カレンダー予定・Meet URL・通知は1件で生成

### 2.2 1時間前キャンセル無料（Q013）

- `cancel_policies` に既存のチケット返金規約に加えて以下を追加：
  - `free_cancel_minutes_before_start` (integer, default: 60)
- 予約キャンセル/変更APIで判定：
  - 開始時刻まで `free_cancel_minutes_before_start` 分以上残っている → 無料（チケット返却 + 全額キャンセル/変更可）
  - それ未満 → チケット消化扱い、半額返金 - 返金手数料（Q013既存規約）
  - 弊社都合（管理者発動 or 講師都合）→ 全額返金（Q013/Q014）

### 2.3 講師ランクと指名料（Q023）

- `instructors.rank` カラムを追加：`gold` / `silver` / `bronze` / `regular`（default: regular）
- ランク別指名料は `system_settings` で集中管理（管理者画面で編集可能）：
  ```json
  {
    "instructor_designation_fees": {
      "gold": 1500,
      "silver": 1000,
      "bronze": 500,
      "regular": 0
    }
  }
  ```
- 予約金額構成：
  - チケット消化（金額0扱い） + 指名料（ランクに応じて） + 交通費（対面のみ）
- ペアレッスン時の指名料：1予約に対して1回分のみ加算（人数倍にはしない）
- Stripe Checkout で指名料を別 line_item として表示

### 2.4 影響を受けるテーブル（前版26→27）

追加：`system_settings`（指名料・通知設定・ポリシー外設定の集中管理）

修正：

- `tickets`: `+lesson_format` (solo/pair), `+duration_min` (60/90)
- `instructors`: `+rank` (gold/silver/bronze/regular), `+nickname`, `+avatar_url`, `+public_bio`
- `reservations`: `+pair_participants` (jsonb), `+designation_fee` (integer)
- `cancel_policies`: `+free_cancel_minutes_before_start` (integer)
- `payments`: line_items 内訳保持

## 3. Phase 0 着手宣言

以下を P0 として実装する：

1. プロジェクト初期化（Next.js 14 / TypeScript）
2. shadcn/ui / Tailwind / ESLint / Prettier
3. ディレクトリ構造 (`/app` Route Group / `/lib` ドメイン分離)
4. 環境変数テンプレート (`.env.example`)
5. Supabase client/server/admin の3種クライアント
6. `lib/encryption` (AES-GCM) のスケルトン
7. `lib/logger` (個人情報除外) のスケルトン
8. README.md（セットアップ手順）
9. `.gitignore` / `.vscode/settings.json`

P0完了時点では認証・DBは未実装。`pnpm install && pnpm dev` でトップ画面のみ表示できる状態をゴールとする。
